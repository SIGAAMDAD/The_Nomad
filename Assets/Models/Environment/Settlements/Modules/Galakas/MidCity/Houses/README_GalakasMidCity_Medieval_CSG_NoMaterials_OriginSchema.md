# Galakas MidCity Pack


## Final Market / Artisan Revision

This revision adds a Golden Gate marketplace pack and specialized merchant/artisan building pass.

Added:
- `DetailComponents/MarketplaceVendorStalls/` with 48 standalone no-material CSG stalls.
- `BuildingTypes/13_GoldenGate_Market_StallClusters/` with quick-place stall cluster assemblies.
- `BuildingTypes/12_Merchant_Artisan_Specialized/` with 16 specialized merchant/artisan buildings.
- New specialized lower modules for forges, merchant halls, dyers, apothecaries, tailors, goldsmiths, printers, glassblowers, rope sellers, and stable tack shops.
- New upper modules with hoists, larger shop windows, vent lofts, drying lofts, and banner/display lofts.
- New roof variants: `AsymmetricGable`, `SawtoothWorkshop`, `MerchantSteppedGable`, `DoubleRidgeMarket`, `ClerestoryMarket`, `ForgeVentGable`, `DormerArcadeLong`, and `OffsetCrossMerchant`.

Targeted existing merchant/workshop BuildingTypes were overwritten with specialized assemblies so blacksmiths, merchants, dyers, cobblers, chandlers, booksellers, covered markets, and similar buildings no longer read as plain residences.
